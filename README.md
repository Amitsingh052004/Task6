# Task6
YEAR() and MONTH() functions extract the year and month from the InvoiceDate (order date) to group data by time periods.

SUM(Quantity * Price) calculates total revenue by multiplying quantity sold and unit price for each row.

COUNT(DISTINCT Invoice) counts unique orders to measure sales volume per month.

GROUP BY groups the data by year and month so aggregation functions operate per period.

ORDER BY sorts results by date or revenue, and LIMIT is used to fetch the top results like highest revenue months.
